Vertical Drill Tutorial  

by Milad Kambari in Tutorials
5.0based on 4 ratings,0 reviews

This is a full process of modeling, unwrapping, and texturing a vertical drill in the lovely blender and substance painter! You should have basic knowledge of these software to follow up correctly.

you can watch the demo here :




Tutorial Contents:

Modeling

3+ hours of modeling process of the vertical drill in the blender, everything is clear, and you can follow up easily on the modeling process.

UV
 
In this part, we use the most powerful software in unwrap area! We load the model in Rizom UV and Unwrap the model in Multi UV Tile(Udims Method)!

Texturing

For the texturing part, Substance painter is the right choice, and we start our process in it by baking mesh maps and categories our model in 2 folder. In the continues, we focus on each folder separately and create the materials. In the end, we used the marmoset toolbag for the final presentation quickly and easily!

Software Used:
Blender
Rizom UV
Substance Painter
Marmoset Toolbag

Level:
Intermediate
Prerequisite Basic knowledge of the software used ( how to navigate and work with primary functions in them )

Attention: the final model and project files don't include this product.
Attention: all videos are unnarrated (it means there are no voice-over videos or subtitles)
